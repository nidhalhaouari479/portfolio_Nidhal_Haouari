# Professional Developer Portfolio

A modern, responsive, and multilingual portfolio website built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- 🌍 **Multilingual**: Full English and French support with instant switching.
- 🌓 **Dark/Light Mode**: System preference detection and manual toggle.
- 📱 **Responsive Design**: Looks great on mobile, tablet, and desktop.
- ⚡ **High Performance**: Built with Vite and optimized for speed.
- 🎨 **Modern UI**: Clean design using Tailwind CSS and Lucide icons.
- ✨ **Animations**: Smooth transitions with Framer Motion.

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

## Project Structure

- `src/components`: Reusable UI components for each section
- `src/locales`: Translation files (en.json, fr.json)
- `src/App.tsx`: Main application layout
- `tailwind.config.js`: Tailwind configuration

## Customization

- **Content**: Update translation files in `src/locales/`
- **Projects**: Edit the `projects` array in `src/components/Projects.tsx`
- **Colors**: Modified in `tailwind.config.js` or `index.css`
